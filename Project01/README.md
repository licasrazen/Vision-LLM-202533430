# Project01: NumPy 기반 학생 성적 분석 및 관리 프로그램

NumPy를 활용하여 학생들의 성적 데이터를 분석하고, 개인별 평균, 수석 학생, 그리고 전체 단일 과목 최고 점수와 해당 학생을 추출하는 파이썬 프로그램입니다.

<br>

## 1. 개발 환경 및 필수 의존성 (Prerequisites)

이 프로그램을 실행하기 위해서는 아래의 라이브러리가 필요합니다.

- Python 3.x 이상
- NumPy (`>= 1.20.0`)


```bash
python main.py  # (실행하시는 파이썬 파일명으로 변경하여 실행하세요)
```

<br>

## 3. 주요 기능 및 구현 내용 (Main Features)

### 학생 명단 정제 (1. 학생 명단)

List Comprehension과 문자열 분할(`.split('_')`)을 활용하여 `zg0505_짱구` 형태의 데이터에서 순수 학생 이름만 추출 및 포맷팅

### 전산 시스템 전체 성적 출력 (2. 전산 시스템에 입력된 모든 성적)

`.flatten()`을 이용해 2차원 성적 배열을 1차원 배열로 펼쳐서 전체 성적 나열

### 고득점 성적 필터링 (3. 85점 이상 개수)

부등호 연산과 `.sum()`을 활용해 전체 성적 중 85점 이상인 점수의 개수 집계

### 학생별 평균 점수 계산 (4. 학생별 평균 점수)

`np.mean(axis=1)`, `zip`, f-string 포맷팅을 조합하여 각 학생의 평균 점수를 소수점 없이 깔끔하게 출력

### 최고 평균 수석 학생 선정 (5. 최고 평균 수석 학생)

`.argmax()`를 이용해 최고 평균을 기록한 학생 이름과 평균 점수 출력

### 단일 과목 최고 점수 및 위치 추적 (6. 단일 과목 최고 점수)

전체 최고 점수의 1차원 인덱스(`argmax()`)를 과목 수(`raw_scores.shape[1]`)로 나누는 몫(`//`)과 나머지(`%`) 연산을 통해, 하드코딩 없이 유연하게 해당 학생과 과목명 매칭

<br>

## 4. 참고 사항 (Notes)

데이터 구조나 과목 개수가 변동되더라도 유연하게 동작할 수 있도록 `raw_scores.shape[1]`을 기준으로 좌표 계산을 수행하도록 설계되었습니다.
